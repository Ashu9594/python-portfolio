02

High-Throughput Distributed Scraping Engine

Proxy-aware crawler across 600+ target endpoints, with anti-bot handling and automated scheduling.

Architecture
Redis-coordinated workers, Scrapy and Selenium fetchers, and rotating proxies in front of each target.
Challenge
Bot defenses, session expiry, and uneven site structures across a large target set.
Result
Scheduled coverage of 600+ endpoints with retries that keep collection running without a daily manual restart.
  • Scrapy
  • Selenium
  • Redis
03

CREDAUX Business Intelligence & Analytics

Interactive dashboards and a PDF OCR extraction engine for reporting that used to wait on static packs.

Architecture
Dash views fed by a Python OCR pipeline that pulls figures out of PDF reports into queryable tables.
Challenge
Unstructured documents and operators who needed rankings and salary insight without a fresh export each time.
Result
Live dashboards replaced static reporting cycles for the metrics the business actually reviews.
  • Dash
  • OCR
  • Python
04

Serverless AWS Cloud Data Pipeline

Event-driven Glue ETL paired with Athena queries and automated CloudWatch alerting.

Architecture
Glue jobs land curated datasets on a schedule and on events. Athena queries the result. CloudWatch alarms watch freshness and failure.
Challenge
Operational visibility without standing up an always-on cluster just to move and check data.
Result
A serverless path from raw drop to queryable history, with alerts when a run misses its window.
  • AWS Glue
  • Athena
  • CloudWatch
